# 🕹️ Shaq-a-Licious

Shaq-a-Licious is a Java-based game project focused on **object-oriented design**, **game logic**, and **interactive UI behavior**.  
It was built to demonstrate core Java programming concepts in a fun, arcade-style format.

This project is showcased on my portfolio as a **featured Java game demo**.
